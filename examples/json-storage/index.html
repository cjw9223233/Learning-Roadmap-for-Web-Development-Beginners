先看兩種狀態

本練習只使用 web-storage-lab-v1，不讀寫主教材進度或舊巡檢範例。瀏覽器可能限制 file: 網址的保存；更換網址、瀏覽器或清除資料也可能影響它。此頁不提供多人共用。
