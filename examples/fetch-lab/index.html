先啟動本機測試伺服器

在專案根目錄執行下列命令，再開啟終端機印出的網址。需已安裝 Python；結束後按 Ctrl+C。

這個專用伺服器只綁定 127.0.0.1，提供虛構資料。一般 python -m http.server 不提供本課的 API 情境。可用 --port 8766 改連接埠。
