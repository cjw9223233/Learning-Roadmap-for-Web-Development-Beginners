    閱讀檔案的順序

    1. inspection.js：沒有 DOM 的資料驗證與統計。
    2. app.js：瀏覽器輸入與畫面。
    3. cli.js：Node.js 命令列入口。
    4. inspection.test.js：以 Node.js 執行相同模組的測試。
    5. package.json：專案類型與 npm scripts；package-lock.json：安裝紀錄。

    本範例無第三方依賴，不需要先安裝套件就能跑 demo、test 或 serve；lockfile 不代表已固定 Node.js、作業系統或所有執行結果。
